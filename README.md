# Terraform: GCP Cloud Run + Postgres + CI/CD

A reusable, documented Terraform module that spins up a Cloud Run service, a Cloud SQL (Postgres) instance, and a GitHub Actions pipeline in a single `terraform apply`.

## Why

Most starter Terraform examples stop at one resource. This module wires together what a small production service actually needs: compute, a database, and the CI/CD to deploy it safely, so it can be dropped into a new project and be useful on day one.

## Stack

Terraform, GCP Cloud Run, Cloud SQL, GitHub Actions

## Architecture

```mermaid
flowchart LR
    Internet((Internet)) -->|HTTPS| CloudRun[Cloud Run service]

    subgraph VPC["Private VPC"]
        CloudRun -->|direct VPC egress<br/>private IP only| CloudSQL[(Cloud SQL<br/>Postgres, no public IP)]
    end

    CloudRun -->|reads DB password| Secret[Secret Manager]
    CloudRun -.runs as.-> SA[Dedicated service account]
    SA -.roles/secretmanager.secretAccessor.-> Secret

    GitHub[GitHub Actions] -->|plan on PR / apply on merge| Terraform[Terraform]
    Terraform -->|provisions| CloudRun
    Terraform -->|provisions| CloudSQL
    Terraform -->|provisions| Secret
```

Cloud SQL has no public IP; it's reachable only over the private VPC that Cloud Run connects to via direct VPC egress. The database password is generated by Terraform, stored in Secret Manager, and read by Cloud Run at container start; it's never a plaintext environment variable or a value you type into a `.tfvars` file.

## Usage

This repository's root **is the module**: call it from your own configuration:

```hcl
module "app" {
  source = "github.com/<you>/terraform-gcp-cloudrun-postgres"

  project_id = "my-gcp-project-id"
  name       = "myapp"

  container_image        = "us-docker.pkg.dev/my-project/my-repo/my-app:latest"
  allow_unauthenticated  = true
}

output "cloud_run_url" {
  value = module.app.cloud_run_url
}
```

See [`examples/simple`](./examples/simple) for a complete, runnable example, and [`variables.tf`](./variables.tf) / [`outputs.tf`](./outputs.tf) for the full list of inputs and outputs.

To run the example directly:

```bash
cd examples/simple
cp terraform.tfvars.example terraform.tfvars
# edit terraform.tfvars with your project_id
terraform init
terraform apply
```

## CI/CD setup

The workflow at [`.github/workflows/terraform.yml`](./.github/workflows/terraform.yml) plans `examples/simple` on every pull request (commenting the plan on the PR) and applies it on every push to `main`. It authenticates to GCP via Workload Identity Federation rather than a downloaded service-account key, so there's no long-lived credential sitting in GitHub secrets.

Getting this running needs a one-time bootstrap in your GCP project, done once by hand (outside Terraform, since Terraform can't create the credentials it will later authenticate with):

1. **A GCS bucket for Terraform state** (state contains the generated DB password, so it must live somewhere durable and access-controlled, not on a CI runner's local disk):
   ```bash
   gcloud storage buckets create gs://YOUR_STATE_BUCKET --location=us --uniform-bucket-level-access
   ```
2. **A Workload Identity Federation pool + provider trusting your GitHub repo**, and **a service account** it can impersonate with permission to manage the resources in this module (`roles/run.admin`, `roles/cloudsql.admin`, `roles/secretmanager.admin`, `roles/compute.networkAdmin`, `roles/iam.serviceAccountAdmin`, plus `roles/iam.workloadIdentityUser` on the service account for the pool). Google's guide: [Configure Workload Identity Federation for GitHub Actions](https://cloud.google.com/iam/docs/workload-identity-federation-with-deployment-pipelines).
3. **Four GitHub Actions secrets**, set on the repo (Settings → Secrets and variables → Actions):

   | Secret | Value |
   |---|---|
   | `GCP_PROJECT_ID` | your GCP project ID |
   | `GCP_WORKLOAD_IDENTITY_PROVIDER` | full resource name of the provider from step 2 |
   | `GCP_SERVICE_ACCOUNT` | email of the service account from step 2 |
   | `TF_STATE_BUCKET` | name of the bucket from step 1 |
